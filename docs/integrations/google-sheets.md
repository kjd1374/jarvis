# Google 시트 작업 공간과 문서 문답

2026-10-17, Issue #30. `/tasks`는 왼쪽 파일·탭 트리, 가운데 표, 오른쪽 짧은 문답으로 구성한다. 데스크톱은 위 작업 공간 80vh와 아래 예약 공간 20vh, 좁은 화면은 세로 배치다. 기존 할 일은 `/tasks?view=records`, 수정 요청은 `/tasks?view=requests`에 보존한다.

## 실제 구현 범위

- Google Identity Services의 브라우저 토큰 모델과 Google Picker로 사용자가 직접 선택한 스프레드시트만 연결한다. `drive.file`은 파일별 권한이며 Google 동의 화면에서 편집 권한도 포함한다. 이번 구현의 Google API 호출은 **GET만** 사용한다. 실제 편집은 Google 원본 새 탭에서 한다.
- Google Sheets API로 선택한 탭의 표시값 전체를 읽는다. 큰 탭은 200행·50열 이하/10,000셀/값 JSON 40,000자 이하 구간으로 나누어 표시한다. 전체 행·열 수와 현재 구간·확인 시각을 구분하고 실패하면 이전 정상 내용을 유지한다. 수식·서식·다른 탭까지 실시간 동기화하는 기능은 아니다.
- 폴더와 고정, 파일 아래 탭 선택, 원본 열기, 자료실 보관과 업무 복귀를 제공한다. 보관은 **실제로 불러온 범위**와 문답을 Jarvis에 남긴다. Google 원본을 옮기거나 삭제하지 않는다.
- 질문을 보낼 때 저장한 범위를 고정한다. 실행기 2.2.0 이상의 `documentVersion: 1` 기능으로 기존 회사/개인·프로젝트 범위 안에서만 요청을 가져간다. GitHub 연결 없이도 동작한다. 보관한 문서에도 질문할 수 있다.
- Mac Codex ChatGPT 구독 로그인으로 도구·셸·웹 검색을 끈 읽기 전용 문답을 수행한다. 선택 범위·질문·같은 범위의 최근 대화 최대 4개를 전달한다. 모델은 근거 행 번호를 반환하고 서버가 실제 범위 안인지 검사한다. 원본 링크는 모델이 아닌 앱에서 생성한다. 별도 API 과금으로 전환하지 않으며 구독 사용 한도가 적용된다.
- 취소·만료·다른 기기/프로젝트/보관 범위의 결과는 거절한다. 완료 응답 재전송은 중복 저장하지 않는다. 전송 실패 재시도는 비공개 로컬 결과 파일을 재사용하며 성공 후 삭제한다. 끊긴 요청은 사용자 재시도 전 자동 모델 재실행하지 않는다. 백업 가져오기도 대기 요청을 중단 상태로 복원한다.
- 일반 자료 검색에도 보관한 시트 범위를 출처·시각과 함께 포함한다. 일반 `/assistant` 자연어 응답은 여전히 별도 미연결이다. 이번 실제 모델 경로는 **문서에 물어보기** 패널이다.

## 최초 Google 설정

사용자는 아직 Google Cloud 설정이 없다고 정정했다. 실제 계정·파일 접근 승인과 Mac 2.2.0 업데이트는 첫 사용 단계이며 합성 테스트 통과와 구분한다.

1. [Google Cloud 프로젝트](https://console.cloud.google.com/projectcreate)를 만든다. 같은 프로젝트에서 **Google Sheets API**, **Google Picker API**를 사용 설정한다.
2. Google Auth Platform의 Branding/Audience에서 앱 이름·지원 이메일을 설정하고, 개인 사용이면 External/Testing과 본인 테스트 사용자를 설정한다. 조직 계정은 관리자의 접근 정책이 적용될 수 있다.
3. 웹 애플리케이션 OAuth 클라이언트를 만든다. Authorized JavaScript origins에 `https://jarvis-zeta-three-77.vercel.app`을 추가한다. 이 브라우저 팝업 방식은 리디렉션 URI와 클라이언트 비밀번호를 사용하지 않는다.
4. 브라우저 API 키를 만든다. 웹사이트 HTTP 리퍼러는 `https://jarvis-zeta-three-77.vercel.app/*`, API 제한은 Google Picker API로 지정한다. 개발용 주소는 필요할 때 별도 키·클라이언트에 추가한다.
5. 프로젝트 번호(문자열 프로젝트 ID가 아닌 숫자), OAuth client ID, 위 브라우저 API 키를 기존 Vercel 프로젝트의 Production 환경에 각각 `GOOGLE_PROJECT_NUMBER`, `GOOGLE_CLIENT_ID`, `GOOGLE_BROWSER_API_KEY`로 설정하고 기존 GitHub 배포 흐름으로 적용한다. 이 세 값은 브라우저 SDK에 전달되는 공개 식별값이다. OAuth client secret·계정 비밀번호·Google 로그인 토큰은 채팅이나 코드에 넣지 않는다.
6. 업무 → 시트 연결 → Google 동의 → 파일 선택 → 선택한 탭 전체 자동 읽기. 큰 탭은 표시 구간을 바꿔 확인한다. 브라우저를 다시 열거나 토큰이 만료되면 불러오기 시 다시 연결한다. 마지막 보관 내용과 문답은 그대로 남는다.
7. 설정 → 구독 CLI 실행기에서 문서의 프로젝트를 포함한 설정 파일을 받고 Mac 설치기를 다시 실행해 2.2.0 이상으로 업데이트한다. 기존 기기 승인/설정은 재사용한다. 문답 패널의 연결 시각은 해당 문서 범위를 지원하는 실행기의 실제 요청을 기준으로 표시한다.

OAuth access token은 브라우저 메모리에만 두며 Jarvis 서버·IndexedDB·localStorage·CLI로 전송하지 않는다. 저장되는 것은 사용자가 읽은 범위/값과 문답이다. 회사/개인 서버 조회·AI 검색·실행기 범위는 계속 분리된다. 사용자에게 Google 토큰이나 인증 JSON을 요청하지 않는다.

## 보관 한도와 검증

문서별 탭 100개, 서로 다른 저장 범위/내용 200개, 문답 500개, 전체 시트 자료 JSON 2,000,000자 한도를 둔다. 동일 범위·동일 값은 보관본을 재사용하며 최신 확인 시각만 갱신한다. 보관본은 다른 기기의 진행 중 질문 근거일 수 있어 자동 삭제하지 않는다. 한도 도달 시 기존 내용은 유지하고 새 저장을 거절한다.

CI는 합성 Sheets API/Picker/CLI 응답과 일회용 로컬 Supabase로 실제 인증·CAS 저장·기기 범위·응답 전달·브라우저 새로고침을 검증한다. 실제 Google 동의와 사용자 구독 호출을 CI에서 수행하지 않는다. API 사용 정책·쿼터는 [Google 공식 한도](https://developers.google.com/workspace/sheets/api/limits)를 확인하며 무제한 무료로 약속하지 않는다.

공식 근거: [token model](https://developers.google.com/identity/oauth2/web/guides/use-token-model), [Picker sample](https://developers.google.com/workspace/drive/picker/guides/sample), [Sheets scopes](https://developers.google.com/workspace/sheets/api/scopes), [values](https://developers.google.com/workspace/sheets/api/guides/values).

## 탭 자동 읽기와 보기 설정 (Issue #32)

Google 연결 직후 첫 탭, 이후 처음 선택하는 탭은 기본 A1:T200을 자동으로 읽는다. 기존 보관본은 즉시 표시하고 다시 불러오기로 최신 값/지정 범위를 갱신한다. 연결이 만료되거나 페이지를 다시 연 경우 보관본은 계속 볼 수 있고, 읽기 버튼으로 Google에 한 번 다시 연결한다. 자동 읽기가 실패하면 버튼으로 재시도하며 자동 팝업/재시도 반복은 하지 않는다. 보관한 문서는 자동 갱신하지 않는다.

열 머리글 오른쪽/행 번호 아래 경계를 드래그하거나 포커스 후 방향키로 크기를 조절한다. 두 번 클릭 또는 Home으로 해당 크기를, 크기 초기화로 탭의 모든 크기를 되돌린다. 크기와 문답 접힘 상태는 브라우저 보기 설정이며 Google 원본과 서버에 저장된 내용/AI 질문 범위에는 영향을 주지 않는다. 문답 접기/열기는 작성 중 질문과 답변을 유지한다.

## 파일 선택창 (Issue #34)

‘시트 연결’은 공식 Google Picker를 한국어·목록 보기로 연다. `drive.file`에서는 썸네일 권한이 없으므로 큰 미리보기 카드를 기본으로 사용하지 않는다. 파일명 검색과 Google의 정렬 기능을 사용할 수 있다. 데스크톱 창은 최대 900×560이며 작은 화면의 크기 처리는 Google SDK에 따른다. Google 내부 색상/레이아웃은 SDK 지원 범위 밖에서 수정하지 않는다.

## 파일 목록과 탭 선택 (Issue #36)

왼쪽에는 폴더와 파일명만 표시한다. 파일 안의 세부 탭은 표 위 ‘탭’ 선택 메뉴에서 고른다. 탭이 하나면 메뉴 대신 이름을 표시한다. 보관한 문서도 같은 위치에서 탭을 바꿀 수 있고, 기존 탭별 자동 읽기와 보관 내용·보기 설정을 유지한다.


## 전체 탭 읽기와 제거 (Issue #38)

처음 선택하는 탭은 전체 표시값을 읽고 기존 일부 범위는 ‘탭 전체 불러오기’로 갱신한다. 끝의 빈 행·열은 제외한다. 화면에는 전체 행·열 수, 읽은 시각, 현재 구간을 표시한다. 큰 탭은 이전/다음 또는 구간 메뉴로 이동한다. AI 문답은 **현재 구간만** 사용하며 다른 구간/탭은 자동으로 함께 보내지 않는다. 기존 실행기 2.2.0과 호환된다.

한 번의 전체 읽기 한도는 50만 셀·값 JSON 150만 자, 응답 8 MB다. 기존 보관본을 합쳐 문서당 200개 구간/전체 시트 JSON 200만 자, 해당 영역의 서버 저장 요청 3.9 MB 예산도 지킨다. 일부 구간만 저장한 뒤 전체 완료라고 표시하지 않는다. 한도 초과 시 기존 내용을 유지하고 Google 원본 열기를 안내한다. 질문 근거를 보존하므로 옛 보관본은 자동 삭제하지 않는다.

‘자비스에서 제거’를 누르면 확인창에서 삭제 범위를 검토한다. 연결·보관 내용·문답과 대화 첨부 연결을 제거하되 대화 글과 Google 원본 파일은 남긴다. 서버 저장이 완료되면 다른 승인 기기에도 반영된다. 나중에 참고하려면 제거 대신 자료실로 보낸다. 실제 사용자 데이터는 개발·검증 과정에서 제거하지 않는다.
