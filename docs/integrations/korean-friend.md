# korean-friend 연결 검토

검토일: 2026-10-14. 저장소: https://github.com/kjd1374/korean-friend
검토 커밋: `8c6f8bf99bbd7bddc7147654dd6d66f7be5ad408`.
이 문서는 연결 가능성 검토이며, Jarvis 연결 기능 구현이나 실제 프로젝트 등록 완료를 의미하지 않는다.

## 판단

기존 앱을 유지하면서 Jarvis에서 프로젝트·개발 업무·자료를 관리하고 실행 주소를 연결할 수 있다.
코드 전체를 Jarvis/Vercel에 그대로 넣어 실행하는 방식에는 서버·저장·네트워크 조정이 필요하다.
첫 단계는 프로젝트 참조 연결이며, 앱 API와 기록 동기화는 별도 단계로 둔다.

## 실제 구조

- Node 18+ 내장 모듈의 `http.createServer`로 실행하는 앱. 외부 패키지 설치 없이 시작한다.
- 정적 HTML/CSS/ES modules와 `#/` 화면 이동. Jarvis는 Next.js 16.4 / React 19 앱이다.
- 로컬 Ollama 또는 OpenAI 호환 외부 API를 Node 서버에서 호출하며, 브라우저에는 NDJSON으로 응답한다.
- 학습 표현·복습·완료 상태는 맥의 `data/learner.json`에 저장한다. 설정·API 키는 `config.json`이다.
- 대화는 현재 브라우저 페이지의 메모리에 있으며 페이지를 새로 열 때 복원하는 서버 저장 기능은 확인되지 않았다.
- API: `/api/config`, `/api/chat`, `/api/warmup`, `/api/translate`, `/api/situations`, `/api/learner`, `/api/notebook`, `/api/lesson-done`, `/api/review`.
- 앱 자체 인증 없이 루프백에 바인딩하는 개인용 구조이며 문서에서는 Tailscale을 통한 접속을 안내한다.

## 연결 단계

| 단계 | 가능한 범위 | 필요한 작업 |
| --- | --- | --- |
| 프로젝트 참조 | Jarvis에서 목표·개발 할 일·결정·자료와 GitHub/실행 주소를 함께 관리 | 프로젝트 상세에 GitHub/서비스 주소 참조 필드를 추가했다. 주소 등록 후 새 탭으로 열 수 있으며 실제 앱 실행 상태나 코드 동기화까지 연결된 것은 아님 |
| 상태 연동 | 학습 앱의 상태나 작업 결과를 Jarvis에서 조회 | 실제 사용 목적에 맞는 제한된 API, 접근 제어, 사설 네트워크 경로를 정해야 함. 공개 Vercel 서버가 맥의 localhost나 개인 Tailscale에 자동 접근하지는 못함 |
| Jarvis 안에서 실행 | 화면 통합이나 전체 이식 | 루트 기준 `/api/*` 경로 충돌·프레임 내 마이크 권한 검토. Vercel 환경에서 JSON 파일을 영구 저장소로 쓸 수 없어 DB/파일 저장 어댑터가 필요. 로컬 Ollama 연결 경로도 별도로 필요 |

기존 학습 앱의 전용 프롬프트·학습자 데이터와 Jarvis의 회사/개인 업무 맥락을 구분한다.
로컬 API의 설정 변경·학습 기록 쓰기 기능을 그대로 공개 인터넷에 노출하는 방식을 선택하지 않는다.
기존 앱의 음성 기능을 유지하는 것은 Jarvis에 별도 TTS 시스템을 도입하는 작업과 구분한다.

## 출처·비용·데이터

사용자가 지정한 저장소를 GitHub의 기존 인증 경로로 읽었다. 변경·설치·자동 시작 스크립트는 실행하지 않았다.
저장소는 archived 상태가 아니며 검토한 버전에는 LICENSE 파일이나 GitHub 인식 라이선스가 없다.
같은 소유자의 프로젝트 내부 연결을 검토하며, 외부 재배포가 필요해질 때 라이선스 범위를 확인한다.
로컬 Ollama는 외부 모델 API 사용료 없이 실행 가능하지만 하드웨어가 필요하다.
외부 API 모드에서는 선택한 제공자에 대화가 전송되고 사용 요금이 발생한다.
브라우저 음성 인식의 처리·전송 방식은 브라우저에 따라 달라 실제 기기에서 확인해야 한다.
새 패키지나 원격 설치 스크립트는 필요하지 않았다.

## 검증

원본 저장소를 건드리지 않고 `/tmp`의 복사본에서 Node 24와 로컬 가짜 AI 서버를 사용했다.
검증 과정의 학습 기록과 설정은 모두 합성 자료이며 종료 시 임시 폴더와 직접 시작한 서버를 정리했다.

1. 앱 HTML 제공.
2. 10개 상황 데이터 로드.
3. 표현 노트 저장과 같은 표현의 중복 저장 방지.
4. 레슨 완료 후 복습 항목 생성.
5. 가짜 AI의 스트리밍 응답.
6. 서버 재시작 후 학습 기록 복원.
7. Chromium에서 화면 이동·가짜 AI 대화·390px 모바일 가로 넘침 확인.

전체 항목 통과. AI 호출 4건은 모두 루프백 가짜 서버로 처리했으며 실제 유료 모델 호출은 0건이다.
주요 JS 파일은 `node --check`도 통과했다.
실제 맥미니/Tailscale 실행 상태, 실제 Ollama·Claude 등 외부 API, 실제 마이크·음성 품질은 미검증이다.
이번에는 코드 검토와 격리 실행만 수행했으며 앱 연결·운영 배포·실제 학습 데이터 변경은 하지 않았다.


후속 변경: 프로젝트 상세 화면과 주소 참조 필드가 추가되었다.
실제 사용자의 한국어 공부 프로젝트나 실행 주소를 자동 등록하거나 맥미니에 연결한 것은 아니다.
